## ═══════════════════════════════════════════════
## SECTION 1: WHAT KIND OF VIDEO THIS STYLE IS FOR
## ═══════════════════════════════════════════════

This style system is designed for **short-form vertical educational/informational videos**
intended for Instagram Reels, TikTok, and YouTube Shorts.

It works for ANY of these content categories:
- Historical facts and timelines
- Country/geography comparisons ("Top 10 countries with solar power")
- Science and nature facts
- Biography and person spotlights
- Finance, economy, statistics
- Rankings and lists
- Product or object origin stories
- Event breakdowns and explainers

The visual language is always: **calm, premium, museum-documentary, editorial.**
Think: a world-class documentary reduced to a 60-second Reel.

## ═══════════════════════════════════════════════
## SECTION 3: THE BACKGROUND — THE #1 VISUAL RULE
## ═══════════════════════════════════════════════

The background is the **single most important constant** in this style.
It NEVER changes. It is the same in every scene, every frame, start to finish.

```
TYPE:            Radial gradient — centre bright, edges darkened (vignette)

CENTRE COLOUR:   #F0EEEC  (very light warm grey — almost white)
EDGE COLOUR:     #C8C4C0  (soft medium warm grey)

GRADIENT SHAPE:  Radial / circular
GRADIENT ORIGIN: Horizontal centre (50%), slightly above centre vertical (45%)
GRADIENT FEEL:   Smooth, gradual — NOT a hard ring, NOT banded

VIGNETTE:        Yes — edges are approximately 20% darker than centre
                 Creates a soft "studio infinity cove" look

TEXTURE:         ZERO — completely smooth, no grain, no paper, no noise
COLOUR TEMP:     Warm grey (slightly warm, not cold/blue)

DO NOT EVER:
  — Change the background between scenes
  — Add colour washes or tints to the background
  — Use white (#FFFFFF) — it must have the warm grey gradient
  — Add bokeh, blur, light leaks, particles, or environmental elements
  — Use a solid flat colour without the gradient
```

**Mental model:** Think of every object in the video as being placed on a perfectly
lit studio table with a seamless warm-grey backdrop. The background is the stage.
Everything else performs on top of it.

## ═══════════════════════════════════════════════
## SECTION 4: TYPOGRAPHY SYSTEM — COMPLETE RULES
## ═══════════════════════════════════════════════

### 4.1 — The Font
```
FAMILY:     One geometric sans-serif — used for 100% of all text in the video
EXAMPLES:   Inter / Montserrat / DM Sans / Nunito Sans
CHARACTER:  Clean, modern, slightly rounded, highly legible at all sizes
RULE:       ONE font family only — no mixing, no display fonts, no decorative fonts
```

### 4.2 — The Two-Weight System
This is the **core typographic identity** of the style. Only two weights exist:

```
WEIGHT A — REGULAR (font-weight: 400)
PURPOSE:   Context, setup, connectors, prepositions, narrative bridges
EXAMPLES:  "For a long time", "it was owned by", "before passing to the",
           "After the partition", "She kept", "They were later presented"
FEEL:      The "voice" — quieter, setting the scene

WEIGHT B — BOLD (font-weight: 700)
PURPOSE:   Subject names, key facts, countries, statistics, important nouns
EXAMPLES:  "the Maratha rulers", "Nadir Shah", "in Bangladesh", "Solar Power",
           "Top 10 Countries", "91 Billion Watts", "Elon Musk"
FEEL:      The "reveal" — louder, the payoff of each sentence

THE GOLDEN RULE:
  Regular weight text always INTRODUCES.
  Bold weight text always DELIVERS THE PUNCH.
  They always appear together — stacked on adjacent lines.
  Regular on top → Bold below (most common)
  OR Bold on top as title → Regular below as descriptor

NEVER use Medium (500) or Light (300) — only Regular and Bold.
```

### 4.3 — Text Colour
```
COLOUR:       #3D3D3D  (dark charcoal — NOT pure black #000000)
OPACITY:      Always 100%
SHADOW:       NONE — zero text shadow ever
STROKE:       NONE — no outline, no border
GLOW:         NONE
BACKGROUND:   NONE — text floats directly on the gradient background
              Never put a pill, card, box, or semi-opaque shape behind text
```

### 4.4 — Font Sizes
```
(All sizes relative to 720px canvas width)

HERO/TITLE TEXT (subject names, key numbers, major reveals):
  Size: 52–62px
  Weight: Bold
  Usage: Proper nouns, country names, important statistics

BODY/NARRATIVE TEXT (setup lines, connectors):
  Size: 42–50px
  Weight: Regular
  Usage: Contextual phrases, narrative connectors

CAPTION TEXT (labels directly under images):
  Size: 30–36px
  Weight: Regular
  Usage: Image labels, sub-descriptors beneath assets

LANDMARK NUMBER/YEAR TEXT (standalone date/stat displays):
  Size: 80–100px
  Weight: Bold
  Usage: A year, a number, or a statistic displayed alone as a moment
  Note: This text type gets its own full scene — no competing elements

3D LOCATION/PLACE TEXT (behind objects):
  Size: 80–110px
  Weight: Bold
  Colour: #8C8884 (lighter grey — blends into background more)
  Style: 3D extruded or large display text sitting BEHIND the main object
```

### 4.5 — Text Alignment & Position Zones
```
ALIGNMENT: Centre-aligned for all multi-line blocks
           Left-aligned ONLY for single words appearing mid-reveal
           (e.g., "It's" appearing alone before the rest of the sentence builds)

POSITION ZONES — the canvas is divided into vertical thirds:

  UPPER TEXT ZONE (Y: 15%–32% from top):
    Used for: narrative setup, first line of a sentence
    The "headline" area — first thing eyes see above the image

  LOWER TEXT ZONE (Y: 62%–80% from top):
    Used for: subject reveal, punchline, bold name, statistic
    The "reveal" area — lands below the image

  CENTRE TEXT ZONE (Y: 42%–55% from top):
    Used ONLY for text-only bridge scenes (no image present)
    When the entire scene is text-only, it sits perfectly centred

  NEVER place text: over the image itself / at extreme top 10% / at extreme bottom 10%
```

### 4.6 — Text Reveal Behaviour (CRITICAL)
```
Text is NEVER shown all at once. It builds progressively within a scene.

STANDARD REVEAL SEQUENCE:
  Step 1: First line (regular weight) fades in — 0.3–0.4s fade duration
  Step 2: Pause 0.5–0.8 seconds (let viewer read it)
  Step 3: Second line (bold weight) fades in — 0.3–0.4s fade duration
  Step 4: Pause 0.5–1.0 seconds
  Step 5: Bottom label or third line fades in (if present)

WITHIN-SENTENCE BUILD:
  Sometimes a sentence grows line by line:
  Beat 1: "For a long time" [appears]
  Beat 2: "it was owned by" [appears below]
  Beat 3: "the Maratha rulers" [appears bold at bottom]
  Each beat is a separate timed fade-in event.

NEVER: Reveal all text simultaneously / use typewriter / use slide-up / use pop/bounce
ALWAYS: Pure opacity fade — 0% to 100% — nothing else
```

## ═══════════════════════════════════════════════
## SECTION 5: IMAGE & ASSET VISUAL SYSTEM
## ═══════════════════════════════════════════════

### 5.1 — The Universal Asset Rule
```
Every visual asset in this style falls into one of 7 types.
Identify which type your asset is, then apply those exact rules.
```

---

### TYPE 1 — CUT-OUT SUBJECT FIGURES
*(People, characters, rulers, scientists, leaders, animals, mascots, etc.)*
```
FORMAT:       PNG with transparent background — NO rectangular frame
PLACEMENT:    Floating directly on gradient background
SIZE:         40–60% of canvas height
POSITION:     Horizontally centred; vertically in lower-mid zone (centre to 75% down)
SHADOW:       Soft drop shadow
              Direction: ~140° (lower-left)
              Blur radius: 28–40px
              Opacity: 25–35%
              Colour: #606060
BOTTOM FADE:  ALWAYS apply a vertical gradient mask to the bottom of the figure
              Opaque at 55–65% of figure height → fully transparent by 85–90%
              Effect: The figure "melts into" the background at its feet/base
              This is NON-NEGOTIABLE — never show a hard bottom edge on a cut-out figure
STYLE:        Can be painting, illustration, 3D render, or photograph — all work
COLOUR:       Preserve original colours (no desaturation unless it's a historical photo)
```

---

### TYPE 2 — HISTORICAL / REAL PHOTOGRAPHS
*(Actual photographs of real people or places — rectangular frame treatment)*
```
FORMAT:       Rectangular crop — NO cut-out treatment
FRAME:        No border, no shadow frame — raw rectangular photo placed on background
SIZE:         55–70% of canvas width
POSITION:     Horizontally centred; occupies upper-mid to lower-mid vertical zone
COLOUR:       Preserve as-is (B&W photos stay B&W, colour photos stay colour)
TREATMENT:    Slight desaturation (10–15%) for cohesion with the muted palette
SHADOW:       Very subtle shadow on the photo rectangle itself (like a floating card)
TEXT:         Subject's name appears ABOVE the photo; role/descriptor BELOW
```

---

### TYPE 3 — PRODUCT / OBJECT RENDERS
*(Jewellery, technology, machinery, food, products, artifacts, scientific objects)*
```
FORMAT:       PNG cut-out, photorealistic quality
PLACEMENT:    Floating on background, centred
SIZE:         45–65% of canvas width (objects are given generous space)
SHADOW:       Same as Type 1 — soft drop shadow
IDLE ANIMATION: Slow, continuous vertical float (see Section 6.4)
              Amplitude: 3–5px up/down
              Duration: 3–5 second loop
              This gives "life" to an otherwise still product image
BOTTOM FADE:  Optional — apply if the object has a visible base/platform
              Skip if the object is naturally floating (e.g., a gem, a ring)
```

---

### TYPE 4 — MAP / GEOGRAPHY SILHOUETTES
*(Country outlines, region shapes, continent forms)*
```
FORMAT:       Flat single-colour silhouette — no labels, no internal detail, no topography
COLOUR:       #C0BCBA (same grey family as background — barely distinguishable)
OPACITY:      30–50% — ghost-like, always secondary to whatever is in front
BLUR:         Slight — 4–8px gaussian blur on edges
SIZE:         60–75% of canvas width
POSITION:     Centred horizontally; mid-canvas vertically
LAYERING:     ALWAYS behind other elements — deepest layer (except background)
PURPOSE:      Context only — "this happened here" — never the hero element
ANIMATION:    Fade in after the figure in front of it has appeared
              Transition: opacity 0% → 35–45% over 0.8–1.0 seconds
```

---

### TYPE 5 — 3D LOCATION / PLACE TEXT
*(City names, country names, place names displayed large in 3D behind objects)*
```
APPEARANCE:   Large bold text + real landmark/building render of that location
              rendered in monochrome grey behind the main subject object
COLOUR:       #888480 (medium-dark grey, blending into background)
OPACITY:      60–75%
STYLE:        3D extruded text OR large flat bold text at ~90–110px
LAYERING:     Behind the main subject object (the object is always in FRONT)
BUILDING:     A greyscale render of a landmark from that city/place appears
              behind and around the text — also grey-toned, 50–70% opacity
POSITION:     Upper-mid canvas, centred — the subject object overlaps from below
ANIMATION:    Fade in after the object is visible — contextual backdrop reveal
PURPOSE:      Communicates location/geography while keeping the hero object primary
```

---

### TYPE 6 — INSTITUTIONAL EMBLEM / LOGO / CREST
*(Organisation logos, country flags, company emblems, institution seals)*
```
FORMAT:       Presented on a CARD — not as a raw cut-out
CARD COLOUR:  #A8A4A0 (medium grey card background — matches overall palette)
CARD SHAPE:   Square, slight border radius (4–6px)
CARD SIZE:    48–55% of canvas width
CARD SHADOW:  Box shadow — more prominent than figure shadows
              Blur: 20–30px, opacity: 30–40%, lower-left direction
EMBLEM:       Sits inside the card, centred, at 70–80% of card size
POSITION:     Centred on canvas, mid-zone vertically
ANIMATION:    Scale 85%→100% + opacity 0%→100% on entry (0.5s ease-out)
```

---

### TYPE 7 — BUILDINGS / ARCHITECTURE
*(Specific buildings, landmarks, structures — shown as the key visual)*
```
FORMAT:       Photorealistic render or real photo, PNG cut-out preferred
COLOUR:       Slightly desaturated — not vivid, not B&W — muted realism
SIZE:         30–50% of canvas width (buildings appear smaller than people)
POSITION:     Lower-centre of canvas — "sitting on the ground"
GROUND EFFECT: White-to-transparent fog at the very base of the building
               Makes it appear to be sitting on the white studio floor
SHADOW:       Long, directional shadow on the ground plane
              Direction: side-left, long (simulates real ground shadow)
              Opacity: 20–30%, very soft
NAME TEXT:    Placed ABOVE the building in bold, ~65–75px
DESCRIPTOR:   Below the building in regular, ~44px
ANIMATION:    Slides in from off-screen RIGHT edge (see Section 6.8)
```

## ═══════════════════════════════════════════════
## SECTION 6: COMPLETE ANIMATION SYSTEM
## ═══════════════════════════════════════════════

### 6.1 — Scene-to-Scene Transition
```
TYPE:     Cross-dissolve / opacity fade
DURATION: 0.3–0.5 seconds
EASING:   Linear or ease-in-out
RULE:     100% of transitions between scenes use this method
          Hard cuts: NEVER
          Wipes: NEVER
          Slides: NEVER (for scene transitions — see 6.8 for in-scene object slides)
          Flash/strobe: NEVER
```

### 6.2 — Standard Object Entry (Within Scene)
```
TRIGGER:  Object appears for first time in scene
TYPE:     Combined opacity fade + scale
OPACITY:  0% → 100%
SCALE:    95% → 100% (origin: object centre)
DURATION: 0.4–0.6 seconds
EASING:   Ease-out (fast start, decelerates to final state)
RESULT:   Object gently "materialises" — grows slightly as it appears
```

### 6.3 — Standard Text Entry (Within Scene)
```
TYPE:     Opacity fade only — NO scale, NO movement, NO slide
OPACITY:  0% → 100%
DURATION: 0.3–0.4 seconds per text element
EASING:   Ease-out
SEQUENCING: Text elements ALWAYS stagger — never appear simultaneously
            Gap between text elements: 0.4–0.8 seconds
```

### 6.4 — Object Idle Float Animation
```
APPLIES TO: Product renders, objects, artifacts (Type 3 assets)
            Does NOT apply to people/figures
TYPE:       Continuous slow vertical oscillation
MOVEMENT:   3–5px upward from rest position, returns to rest
DURATION:   Complete cycle: 3.5–5 seconds
EASING:     Sine wave (perfectly smooth oscillation — no jerking)
OPACITY:    Stays 100% — no pulsing
LOOP:       Infinite, seamless
PURPOSE:    Makes product images feel "alive" without being distracting
```

### 6.5 — Map Overlay Entry
```
TYPE:     Opacity fade only
FROM:     0%
TO:       35–45% (never reaches 100%)
DURATION: 0.7–1.0 seconds
TIMING:   Appears AFTER the figure/object in front of it has already appeared
          Delay: 0.5–0.8 seconds after subject figure is visible
EASING:   Ease-in-out
```

### 6.6 — Figure Rising Through Year/Number
```
TRIGGER:  Year or large statistic number is displayed, then a figure is introduced
SEQUENCE:
  Step 1: Year/number fades in large and centred (0.4s fade)
  Step 2: Figure enters from BELOW the canvas — slides up from ~110% Y
  Step 3: Figure arrives overlapping the year — figure is in FRONT (higher z-index)
  Step 4: The year text is now partially obscured by the figure (intentional)
MOVEMENT: Figure slides up 15–20% of canvas height over 0.7–1.0 seconds
EASING:   Ease-out cubic
EFFECT:   The year becomes a "stage backdrop" the character steps in front of
```

### 6.7 — Portrait Photo Entry
```
TYPE:       Opacity fade + very subtle scale
OPACITY:    0% → 100%
SCALE:      97% → 100%
DURATION:   0.5 seconds
SEQUENCE:   Photo rectangle appears first →
            Name text above fades in (0.3s delay) →
            Role/descriptor below fades in (0.3s further delay)
```

### 6.8 — Building / Architecture Slide-In
```
TRIGGER:   A building or architectural structure is introduced as the scene's hero
TYPE:      Horizontal slide from OFF-SCREEN RIGHT + opacity fade
STARTING X: ~110% of canvas width (fully off right edge)
ENDING X:  Centre of canvas
OPACITY:   0% → 100% during travel
DURATION:  0.7–1.0 seconds
EASING:    Ease-out cubic (decelerates to stop at centre — satisfying landing)
THEN:      After building arrives and settles:
           Name text above fades in (0.3s delay)
           Descriptor text below fades in (further 0.3s delay)
```

### 6.9 — Text-Only Scene Entry
```
TRIGGER:   A "bridge" scene with no images
TYPE:      Opacity fade
FIRST LINE (regular weight): fades in at Y:50% centre
SECOND LINE (bold weight): fades in 0.4–0.6 seconds later
DURATION:  0.3s per line
HOLD TIME: Minimum 1.2 seconds on screen before scene ends
```

### 6.10 — Comparison / Side-by-Side Animation
```
TRIGGER:   Two objects or options are shown for comparison
SEQUENCE:
  Step 1: Both objects appear simultaneously (standard 6.2 entry)
          Left object slightly smaller / right object same size OR vice versa
  Step 2: Labels appear under each (standard 6.3 text entry)
  Step 3: One object SCALES UP to become dominant (scale 1.0 → 1.3x over 0.5s)
          This communicates "this one is more important/larger/the subject"
  Step 4: That object's label also boldifies or increases in size
```

## ═══════════════════════════════════════════════
## SECTION 7: SCENE STRUCTURE TYPES
## ═══════════════════════════════════════════════

Every scene in a video using this style falls into one of these 8 types.
Your AI agent should identify which scene type to use at each narrative beat.

---

### SCENE TYPE A — HOOK OPENER
```
WHEN:     First 1–3 seconds of the video
PURPOSE:  Immediate visual hook — grab attention instantly
LAYOUT:   SINGLE IMAGE ONLY — no text
CONTENT:  The most visually striking object related to your topic
          (A crown, a product, a landmark, a gem, a logo)
DURATION: 2–3 seconds
TEXT:     NONE
EFFECT:   Viewer sees something beautiful and mysterious — they want to know more
```

### SCENE TYPE B — NARRATIVE SETUP + IMAGE
```
WHEN:     Introducing a new fact, person, or concept
PURPOSE:  Give context + reveal the subject
LAYOUT:
  TOP ZONE:    Regular weight text — the context/setup sentence
  CENTRE:      Subject image (Type 1–3 asset) floats here
  BOTTOM ZONE: Bold weight text — the subject name or key fact
TEXT REVEAL: Progressive (regular first → bold last)
DURATION:    3–5 seconds
```

### SCENE TYPE C — TEXT-ONLY BRIDGE
```
WHEN:     Between scenes to connect narrative; approximately every 8–12 seconds
PURPOSE:  Narrative breath — palette cleanser — reader/listener catch-up
LAYOUT:   TEXT ONLY — no images, no maps, no assets
TEXT:     1–2 lines, centred at vertical midpoint
          Regular weight first line + Bold weight second line
DURATION: 1.5–3 seconds
EFFECT:   Creates rhythm — the absence of images makes the next image more impactful
```

### SCENE TYPE D — FIGURE REVEAL
```
WHEN:     Introducing a specific person, ruler, scientist, CEO, leader, etc.
PURPOSE:  Put a face to a name — human connection
LAYOUT:
  TOP:    "[Role/descriptor]"  [regular weight]  e.g., "the Persian ruler"
  MID:    Figure cut-out (Type 1 — with bottom fade + shadow)
  BOTTOM: "[Full Name]"  [bold weight]  e.g., "Nadir Shah"
EXTRA:    Map silhouette (Type 4) can fade in BEHIND figure after name appears
DURATION: 3–5 seconds
REVEAL:   Role text → figure → name text (staggered)
```

### SCENE TYPE E — LOCATION/PLACE REVEAL
```
WHEN:     Showing where something happened or is located
PURPOSE:  Geographic context
LAYOUT:
  BACKGROUND LAYER:   Map silhouette (Type 4) — ghost opacity
  MID LAYER:          3D location text + landmark render (Type 5)
  FRONT LAYER:        Main subject object (Type 3) in FRONT of everything
  TEXT TOP/BOTTOM:    Narrative text in upper and lower zones
DURATION: 3–5 seconds
EFFECT:   Layered depth — location wraps around the subject object
```

### SCENE TYPE F — YEAR / STATISTIC MOMENT
```
WHEN:     A specific year, date, or large number needs to land with impact
PURPOSE:  Make numbers feel cinematic and memorable
LAYOUT:
  Step 1: Large number/year ONLY — centred, ~90–100px bold — pure screen moment
  Step 2: Relevant figure/image rises UP through the number (Section 6.6)
  Step 3: Contextual text fades in around the figure/number combination
DURATION: 3–4 seconds total
```

### SCENE TYPE G — COMPARISON / CHOICE
```
WHEN:     Comparing two options, objects, paths, or outcomes
PURPOSE:  Visual decision-making moment — creates narrative tension
LAYOUT:
  TOP:         Setup question or context  [regular]
  MID-LEFT:    Option A (smaller/rejected)  [with label below]
  MID-RIGHT:   Option B (larger/chosen)  [with label below]
  OPTIONAL:    A figure between or above both options (like Queen Victoria choosing)
ANIMATION:  One option scales up to show dominance (Section 6.10)
DURATION:   4–6 seconds
```

### SCENE TYPE H — BUILDING / INSTITUTION REVEAL
```
WHEN:     Introducing an institution, organisation, building, or final destination
PURPOSE:  Conclusion, current status, or institution reveal — often used as endings
LAYOUT:
  Building slides in from right (Section 6.8)
  Name text above building  [bold, ~65–75px]
  Descriptor line below building  [regular, ~44px]
  Second descriptor line below  [bold]  e.g., "in Bangladesh"
DURATION: 4–5 seconds
POSITION: Often used as the FINAL SCENE or a major reveal scene
```

## ═══════════════════════════════════════════════
## SECTION 8: NARRATIVE & PACING RULES
## ═══════════════════════════════════════════════

```
PACING PHILOSOPHY:
  This is a "breathing" video — never rushed, never crowded.
  Each idea gets space to land before the next one arrives.
  The pace feels like a confident narrator who knows the audience is hooked.

THE GOLDEN RHYTHM (repeat this pattern):
  [SCENE TYPE B: introduce concept]
  [SCENE TYPE D: reveal the person/subject]
  [SCENE TYPE C: text-only bridge connecting to next idea]
  [SCENE TYPE B or E: next concept]
  ...repeat...

MINIMUM ON-SCREEN TIMES:
  Any text element:        0.8 seconds minimum before change
  Any image/asset:         1.5 seconds minimum before exit
  Text-only bridge scenes: 1.5 seconds minimum
  Major reveal moments:    2.5–3.0 seconds (let it breathe)

THE REGULAR → BOLD SENTENCE STRUCTURE:
  Every factual statement follows this two-part structure:
  Part 1 (regular): "For a long time, it was owned by..."
  Part 2 (bold):    "...the Maratha rulers"
  
  This ALWAYS applies — even if your topic is "Top 10 Solar Countries":
  Part 1 (regular): "The country producing the most solar energy is..."
  Part 2 (bold):    "China"

THE RECURRING VISUAL ANCHOR:
  Choose ONE hero object/image that represents your topic's main subject.
  Return to this same object multiple times throughout the video.
  When showing location changes or time passing, keep this object on screen
  and change the BACKGROUND CONTEXT behind it — not the object itself.
  This creates continuity and always re-orients the viewer.
  Example: The Daria-i-Noor ring stayed fixed while city names changed behind it.
  Apply same logic to: a product, a flag, a logo, a chart element, a person, etc.

TEXT-ONLY BRIDGE FREQUENCY:
  Insert a text-only bridge scene (Type C) every 8–12 seconds.
  This creates visual rhythm and prevents the viewer from feeling overwhelmed.

SCENE LENGTH GUIDELINES:
  Hook opener:              2–3 seconds
  Standard narrative scene: 3–5 seconds
  Text-only bridge:         1.5–3 seconds
  Major reveal:             4–6 seconds
  Ending scene:             4–6 seconds (give the conclusion room to breathe)
```

## ═══════════════════════════════════════════════
## SECTION 9: ABSOLUTE DO-NOT-DO RULES
## ═══════════════════════════════════════════════

These rules apply to EVERY video made in this style, regardless of topic.
Violating these breaks the aesthetic identity of the style.

```
BACKGROUND:
  ❌ Never change the background between scenes
  ❌ Never use white (#FFFFFF) as background — always warm grey gradient
  ❌ Never add colour overlays, tints, or vignettes beyond the standard gradient
  ❌ Never add grain, noise, texture, bokeh, or particles to background

TYPOGRAPHY:
  ❌ Never use more than one font family
  ❌ Never use font weights other than Regular (400) and Bold (700)
  ❌ Never colour text anything other than #3D3D3D charcoal
  ❌ Never add text shadows, strokes, glows, or embossing to text
  ❌ Never place text on a coloured pill, badge, box, or semi-opaque background
  ❌ Never use ALL CAPS — always sentence case or title case
  ❌ Never show all text at once — always reveal progressively
  ❌ Never use more than 3 lines of text in a single scene

ANIMATIONS:
  ❌ Never use wipe, swipe, slide, or push transitions between scenes
  ❌ Never use typewriter, bounce, pop, flip, or spin text animations
  ❌ Never use zoom-in/zoom-out as a scene transition
  ❌ Never use flash or strobe effects
  ❌ Only fade transitions between scenes — always

IMAGES & ASSETS:
  ❌ Never show a cut-out figure with a visible hard bottom edge — always fade out at base
  ❌ Never show two figures/people side-by-side (except in explicit comparison scenes)
  ❌ Never place a rectangular border or decorative frame around cut-out figures
  ❌ Never use vivid, saturated, or neon-coloured images without desaturation
  ❌ Never crowd multiple asset types into the same scene simultaneously

LAYOUT:
  ❌ Never place text over the image itself
  ❌ Never use the extreme top 10% or bottom 10% of the canvas for any element
```
