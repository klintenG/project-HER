## SECTION 3: GLOBAL TYPOGRAPHY SYSTEM
## ═══════════════════════════════════════

### 3.1 — Font Family
```
FONT: Single geometric sans-serif throughout entire video
CLOSEST MATCH: "Inter", "Montserrat", or "DM Sans"
STYLE: Clean, modern, no serifs, slightly rounded geometry
DO NOT MIX fonts — one font family for the entire video
```

### 3.2 — Text Weight System (TWO weights only)
```
WEIGHT A — REGULAR/LIGHT (for secondary/contextual phrases):
  Font weight: 400 (Regular)
  Used for: setup text, prepositions, narrative connectors
  Example lines: "if Queen Victoria", "For a long time", "before passing to the", "in the"

WEIGHT B — BOLD/SEMIBOLD (for subject names and KEY facts):
  Font weight: 700 (Bold) or 600 (SemiBold)
  Used for: proper nouns, names, key historical facts
  Example lines: "The Kohinoor", "Daria-i-Noor", "Nadir Shah", "the Maratha rulers", "Punjab", "in Bangladesh"

RULE: These two weights ALWAYS appear together in a text block.
The regular weight sets up context; the bold weight delivers the punchline/name.
They sit on adjacent lines, stacked vertically.
```

### 3.3 — Text Colour
```
PRIMARY TEXT COLOR: #3D3D3D (dark charcoal, NOT pure black)
OPACITY: 100% always
SHADOW: None. Zero text shadow.
STROKE/OUTLINE: None
BACKGROUND behind text: None (text floats directly on background gradient)
```

### 3.4 — Font Sizes (relative to 720px wide canvas)
```
LARGE BOLD TEXT (subject names, key words): ~52–60px
REGULAR SETUP TEXT (connector phrases): ~44–50px
SMALL CAPTION TEXT (labels below images): ~32–36px
YEAR/NUMBER STANDALONE TEXT: ~80–100px (displayed large and centered as a moment)
```

### 3.5 — Text Alignment
```
ALIGNMENT: Centre-aligned for ALL multi-line text blocks
WHEN TEXT IS LEFT-ALIGNED: Only for single-word or short connector words 
  appearing at the left edge mid-scene (e.g., "It's" appearing alone, or "in the" mid-reveal)
LINE SPACING: 1.1–1.2x line height (tight but not overlapping)
LETTER SPACING: Default / 0 tracking — no unusual spacing
```

### 3.6 — Text Positioning on Canvas
```
TEXT BLOCK — TOP ZONE:
  Used for: scene narrative/setup
  Y position: 18%–30% from top of canvas
  X position: Horizontally centred (10% margin each side)

TEXT BLOCK — BOTTOM ZONE:
  Used for: subject label or punchline word
  Y position: 65%–80% from top of canvas
  X position: Horizontally centred

TEXT BLOCK — MIDDLE ZONE (text-only scenes):
  Y position: 45%–52% (perfectly centred vertically)
  Used when: NO image is present in the scene — pure text bridge moment
```

## SECTION 5: ANIMATION SYSTEM & TRANSITIONS
## ═══════════════════════════════════════

### 5.1 — Scene Transition (Between Scenes)
```
TYPE: Cross-dissolve / fade
DURATION: 0.3–0.5 seconds
EASING: Linear or ease-in-out
HARD CUTS: None — every scene transition is a fade
FLASH: None
WIPE/SLIDE: Never used
```

### 5.2 — Object Entry Animation (Within a Scene)
```
ENTRY TYPE: Fade-in combined with subtle scale
SCALE: Object starts at 95% and scales to 100%
OPACITY: Starts at 0%, reaches 100%
DURATION: 0.4–0.6 seconds
EASING: Ease-out (starts fast, slows to final position)
DIRECTION: No directional movement — purely opacity + scale from centre
```

### 5.3 — Text Entry Animation
```
ENTRY TYPE: Fade-in only (no movement, no slide, no typewriter)
OPACITY: 0% → 100%
DURATION: 0.3–0.4 seconds per text element
SEQUENCING: Text phrases appear one by one or in groups, NOT all at once
  — Setup phrase (regular weight) appears FIRST
  — Bold subject name appears SECOND (0.3–0.8s after setup text)
  — Bottom label appears LAST
EASING: Ease-out
```

### 5.4 — Object Float / Idle Animation
```
TYPE: Extremely slow, subtle vertical float
DIRECTION: Gentle upward drift (2–4px total movement)
DURATION: Loops over 3–5 seconds
AMPLITUDE: Nearly imperceptible — creates "alive" feel on still renders
EASING: Sine wave (smooth oscillation)
APPLIES TO: Jewellery renders, diamond cuts — not to figures
```

### 5.5 — Map Entry Animation
```
TYPE: Fade-in behind existing figure
OPACITY: 0% → 40% (never fully opaque)
DURATION: 0.6–1.0 second
TIMING: Appears after the figure is already visible
EFFECT: Contextual layer that materialises behind the character
```

### 5.6 — Portrait Photo Entry Animation
```
TYPE: Fade-in as complete rectangle
OPACITY: 0% → 100%
SCALE: 97% → 100%
DURATION: 0.5 seconds
PHOTO appears first, then text above and below fade in sequentially
```

### 5.7 — Institutional Card Animation
```
TYPE: The card (East India Company) drops in or materialises
EFFECT: Scale from 85% → 100% + fade
DURATION: 0.5 seconds
SHADOW: Grows in alongside the card
```

### 5.8 — Building/Architecture Entry
```
TYPE: Horizontal slide from off-screen RIGHT + fade
DISTANCE: Enters from about 110% of canvas width
ARRIVES AT: Centre of canvas
DURATION: 0.8–1.0 second
EASING: Ease-out cubic
SIMULTANEOUSLY: Text elements ("Sonali Bank", "a state-owned bank", "in Bangladesh") 
                fade in after the building has arrived
```

### 5.9 — Year Number Animation
```
TYPE: Large number (e.g., "1907") fades in centred
THEN: A historical figure RISES UP through/over the year number
OVERLAP: The figure physically overlaps the number (figure in front, number behind)
EFFECT: Feels like the year is a backdrop/stage the character walks into
YEAR TEXT SIZE: ~90–100px, bold, centred
```
