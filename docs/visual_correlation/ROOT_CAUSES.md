## Active route and preserved contracts

Topic, URL, article, supplied account and specialized story routes keep their existing routing. The reference-editorial preset continues to approve narration before TTS. Event planning never rewrites it or upgrades supplied assertions into verified facts. Existing verbatim behavior is not changed.

`run_editorial` starts `news_audio.synthesize` against the approved original sections while visual planning runs. `audio.prepare_existing` validates provider timing or aligns actual audio. The event binder reassigns section IDs only; word IDs, text and timestamps must remain in exactly the same order. Captions use those same words. `planner.build` and the existing director/reference choreography retain ProjectHER fonts, watermark, safe regions, emphasized words and closing package.
